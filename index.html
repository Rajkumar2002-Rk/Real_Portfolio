AI Financial Research Agent

GPT-4o · FastAPI · Redis · Docker · AWS EC2

The Problem

Financial analysts spend days compiling research from 10+ scattered sources — market data, news, SEC filings, fundamentals. Manual work doesn't scale and introduces inconsistency.

The Solution

An autonomous GPT-4o agent that uses tool-calling to fetch live data from Alpha Vantage, NewsAPI, and financial APIs, then synthesises a structured investment research report in under 30 seconds.

Architecture

FastAPI backend → GPT-4o agent loop → tool dispatcher (market data / news / fundamentals) → Redis cache layer → structured Markdown report. Deployed via Docker Compose on AWS EC2.

Key Results

  • Research report generated in under 30 seconds
  • Redis caching achieves 10× API cost reduction on repeated queries
  • Live deployment on AWS EC2 with Docker Compose
  • Supports stocks, ETFs, and market sector analysis

Enterprise RAG Chatbot

LangChain · ChromaDB · GPT-4 · Streamlit · AWS EC2

The Problem

Enterprise knowledge locked in PDFs, Word docs, and internal wikis means employees waste hours on search instead of work. Generic chatbots hallucinate without grounding.

The Solution

A production RAG pipeline: documents are chunked, embedded, and stored in ChromaDB. LangChain retrieves relevant chunks and passes them to GPT-4 for accurate, grounded responses with streaming.

Key Results

  • 87% retrieval accuracy on benchmark query set
  • Supports PDF, DOCX, and TXT ingestion
  • Real-time streaming responses via Streamlit
  • Deployed on AWS EC2 with Docker

AWS Retail Sales Forecasting

LSTM · Prophet · SageMaker · S3 · PyTorch

The Problem

Single-model forecasts fail to capture both long-range trends and short-range seasonality simultaneously, causing inventory errors that cost retailers millions annually.

The Solution

Ensemble of LSTM (complex temporal patterns) and Prophet (seasonality + holidays). Trained on 2 years of multi-store data, deployed as a SageMaker endpoint with automated weekly retraining from S3.

Key Results

  • 4.2% RMSE across 45 product categories
  • 18% improvement over single-model baselines
  • 8-week forecast horizon with weekly auto-retraining
  • Fully automated pipeline on AWS SageMaker

Customer Churn Prediction

XGBoost · SHAP · MLflow · Docker · GitHub Actions

The Problem

Acquiring new telecom customers costs 5× more than retaining existing ones. Without early warning signals, at-risk customers leave before retention campaigns can reach them.

The Solution

XGBoost classifier trained on 21 engineered customer features, with SHAP waterfall plots providing individual prediction explanations. MLflow tracks all experiments; Docker packages the inference API; GitHub Actions automates retraining.

Key Results

  • SHAP explanations for every individual prediction
  • Automated retraining pipeline via GitHub Actions
  • Fully containerised inference API with Docker

Insurance Fraud Detection

YOLOv8 · ResNet-50 · PyTorch · OpenCV · FastAPI

The Problem

Insurance companies process 50,000+ claims annually. Manual review is slow, expensive, and inconsistent — letting fraudulent claims slip through while delaying legitimate ones.

The Solution

Dual-model computer vision pipeline: YOLOv8 localises and detects vehicle damage in real time, while ResNet-50 classifies severity and flags fraud indicators. Served via FastAPI at 50ms latency.

Key Results

  • 96.7% fraud detection accuracy on 50k+ claim images
  • 50ms average inference latency
  • Dual-model pipeline for detection + classification
  • REST API deployment via FastAPI
