AI Financial Research Agent

GPT-4o · FastAPI · Redis · Docker · AWS EC2

The Problem

Financial analysts spend days compiling research from 10+ scattered sources — market data, news, SEC filings, fundamentals. Manual work doesn't scale and introduces inconsistency.

The Solution

Designed and deployed a deterministic investment decision engine — a 7-step async LangGraph pipeline that generates auditable BUY/HOLD/SELL recommendations in under 30 seconds. GPT-4o is constrained to explanation-only: zero influence over the decision, ensuring fully reproducible and auditable outputs with zero hallucination risk on recommendations.

Engineering Decisions

Normalized multi-factor scoring engine (Technical 0–25, Fundamental 0–40, Sentiment 0–15) with dynamic max adjustment — missing data excluded from denominator rather than penalised, eliminating false SELL signals. Conflict-aware decision logic: signal disagreement (variance > 0.15) overrides to HOLD in 35–55% ambiguity band, reducing false conviction. 5-factor confidence model (data completeness, signal agreement, volatility, news uncertainty) blocks recommendations below 20% confidence. Redis TTL 900s caching reduces repeated query latency from ~15s to <100ms.

Business Value

Any firm paying analysts $80k+/year offsets that cost with sub-30s deterministic decisions. Portfolio ranking mode supports 2–8 tickers with proportional capital allocation. The same architecture extends to portfolio monitoring, earnings alerts, and competitive intelligence at near-zero marginal cost per use case.

Key Results

  • BUY/HOLD/SELL decision generated in under 30 seconds
  • Repeated query latency: ~15s → <100ms via Redis caching (10× API cost reduction)
  • Zero LLM hallucination risk — GPT-4o explains decisions, never makes them
  • Portfolio ranking mode: 2–8 tickers with proportional capital allocation
  • Live on AWS EC2 with Nginx domain routing and Docker Compose

CineNeuro — Neural Audience Intelligence

Meta FAIR TRIBE v2 · V-JEPA2 · Wav2Vec-BERT · Llama 3.2 · FastAPI · React · AWS EC2

The Problem

Film studios spend millions producing trailers with no way to quantify emotional impact before release. Traditional test screenings are expensive, slow, and limited to small samples — there's no second-by-second signal showing where audiences peak in excitement, disengage, or feel fear.

The Solution

CineNeuro uses Meta FAIR's TRIBE v2 brain encoding model to predict fMRI activations across 20,484 cortical vertices for every second of a trailer. Three feature extractors process the video simultaneously — V-JEPA2 for visual content, Wav2Vec-BERT for audio waveforms, and Llama 3.2 for transcript embeddings. These feed TRIBE v2, and the predicted activations are mapped to 5 emotion channels (excitement, fear, joy, suspense, boredom) across 7 functional brain regions using neuroscience-based weights.

Engineering Decisions

Two-tier deployment strategy: a g4dn.xlarge GPU instance (Tesla T4, 15GB VRAM) handles inference on-demand at $0.53/hr, then terminates. A t3.micro serves the React dashboard 24/7 at near-zero cost using pre-computed JSON results (<100ms load time). The three extractors total 12.89GB (V-JEPA2 4.14GB + Wav2Vec-BERT 2.32GB + Llama 3.2 6.43GB) — barely fitting in 15GB VRAM, requiring careful sequential model loading. Multi-stage Docker build (Node 18 + Python 3.11-slim) keeps the production image at ~500MB with no ML weights. Submitted PR #20 to Meta FAIR's TRIBE v2 — added int8 compute_type fallback for WhisperX on non-CUDA devices. Before the fix: hardcoded float16 caused ValueError on Apple Silicon and CPU-only Linux. After: the full pipeline runs everywhere. CUDA path unchanged, <1% WER degradation on transcription accuracy. CLA signed, checks passing.

Business Value

Second-by-second emotion maps identify the 3 strongest and 3 weakest trailer moments with human-readable explanations — directly actionable edit intelligence. Competitive benchmarking against 5 iconic trailers (Oppenheimer, Avengers Endgame, Inception, Interstellar, The Dark Knight) gives studios a quantified baseline. Full analysis costs ~$0.50 in GPU time vs thousands for a traditional test screening.
